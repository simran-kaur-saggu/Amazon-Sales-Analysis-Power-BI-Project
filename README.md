# Amazon-Sales-Analysis-Power-BI-Project

This project presents an interactive Power BI dashboard that analyzes sales data for Amazon products across different categories, time periods, and regions.


## Objective
To provide actionable insights into **sales trends**, **top-performing products**, **revenue growth**, and **customer behavior** using visual analytics in Power BI.


## Key Insights
-  **Top Selling Products** by revenue and quantity
-  **Sales by Region** to identify high and low performing markets
-  **Monthly/Quarterly Trends** in sales and profit
-  **Category-wise Performance** and profit margin
-  Filters for dynamic exploration by year, region, product category, and more

---

## Tools & Technologies
- **Power BI Desktop**
- Data cleaning and transformation using **Power Query**
- Interactive visuals including **bar charts**, **line charts**, **maps**, **slicers**, and **cards**
